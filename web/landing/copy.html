The toolbox your agent was missing.

Software engineering is not so much about writing code anymore – it's about managing complexity with our coding agents. nock is a framework that records their work and helps them reflect on how to make it better.

Reflection Agents that write the tools they need.

nock instruments your agents: every call and session is recorded on your machine, never committed. Every week or so a reflection round reads that record and the work since. It writes the tools that would have saved turns, repairs the ones that misbehave and retires the ones nobody uses, and the next run holds each change to what it expected.

Reflection rounds nock in Logika The reflection round that catches bugs before they happen.

Logika is observability and analytics for coding agents. It runs its reflection round on nock: in the logika round, your agent reads Logika's map, what each event logs and which events no rule reads yet, and writes the rules with you from real captures. Logika then checks every span against them, so a bug is caught as an issue with its evidence before anyone notices it.

Getting started

From uvx nock init to your first verdict on what an agent made: seven steps, about ten minutes, in a repository of your own.

  • Step 1

    Install it in your repository

    Inside the repository, run uvx nock init (or pipx run nock init). It vendors nock into .nock/core/, writes .nock/config.toml, a primer CLAUDE.md imports, the agent's hooks and permissions, and the skills.

  • Step 2

    Commit it

    nock is your project's own code now, so it goes in git. Telemetry stays out: .nock/local/ is ignored, and never leaves your machine.

  • Step 3

    Make your tests the gate

    Add your test suite and linters as checks. Tools and reflection rounds must pass them, and .nock/nock check prints nothing when they do.

  • Step 4

    Work as you always do

    Start your coding agent and ask for something. Every session reads nock's primer through CLAUDE.md, and is recorded: what you asked, each tool call, what failed, what it cost.

    • What happens next

    After 10 sessions, a session start says the nock round is due; run /nock-reflect in a session, and read its report. Your agents' tools grow from there.
