A community learning to work with AI, as software engineers.

A coding agent starts every session knowing nothing of the last one: not what was decided yesterday, or why; not what you said about it; not which script someone wrote to do what it is about to do by hand. Over weeks, the project drifts: the same question answered three ways, a simplification nobody approved, the same mistake made again.

The usual fix is prose, and prose goes stale without anyone noticing. A command that no longer fits breaks, and the failure is recorded. A check beats a hook beats prose.

You are there for the one thing no agent can infer: what the system is for. nock is engineers learning to work this way, and the toolbox they learn with: open source, in your repository, built by your coding agents for themselves.

Reflection

Agents that get better at your project.

Every call and session is recorded on your machine: what you asked, each tool call, what failed, what it cost. Every week or so a reflection round reads that record and the decisions made since: it builds tools for the work that keeps costing turns, repairs the ones that misbehave, and retires the ones nobody uses. What it builds is live on the next call, and the next round holds each change to what it expected.

Review

You judge what agents made, when it suits you.

Agents never wait on you. They record the choices they make with the alternatives they weighed, and register what they make for you to see: screenshots, videos, pages, texts. On nock studio you approve, reject or note each; a note can have it made again, by its recipe or by an agent given your note, as its next version.

Evaluation

Know whether a change makes your agents better.

An evaluation answers it with real runs: a Snakemake workflow in git beside the code, each output cached under its provenance, so the next question costs only what changed and anyone can run it again. Read the results with SQL; compare the arms with bootstrap intervals.

Logika

Your agent hears when production breaks, and fixes it.

Logika is OpenTelemetry that wakes your agent whenever something breaks. Within five minutes it raises an issue with its evidence; your own agent, on your own machine, takes it, fixes it and delivers the fix the way your repository delivers anything, and its report lands in the same email thread. nock's logika round writes, with you, the rules it checks.
