nock
Docs GitHub

A toolbox your coding agents build for themselves.

nock records what your Claude Code sessions do, and turns what keeps costing them turns into tools — code that breaks loudly when it stops fitting, instead of notes that quietly go stale.

uvx --from git+https://github.com/logika-labs/nock nock init
Why

Prose goes stale. Code breaks.

Agents repeat themselves: the same commands to find out why a test fails, the same throwaway script, the mistake you already corrected twice. The usual fix is prose — skills, notes, rules — but a paragraph that no longer fits still reads as true, and nobody can tell whether an agent followed it.

A command that no longer fits fails, and the failure is recorded. So a toolbox can be kept honest by measuring it.

Why nock exists →
A check beats a hook beats prose. A rule a check enforces cannot be ignored. A behaviour a hook triggers cannot be forgotten. Prose is the last resort.
How it works

Work, record, reflect, repeat.

A toolbox in your repository. .nock/nock is a CLI whose commands are your project's own code, written by agents for agents. A tool is a function; nock owns the arguments, output, exit codes and help.

Every run recorded. Each call and each session — what you asked, every tool call, what failed, what it cost — goes into a local database that is never committed.

Decisions you review. Agents never wait on you: they record the choices they make, with the alternatives they weighed, and you accept or reject them when you like.

Reflection rounds. Every week or so, agents read the record, improve the toolbox, keep the map of decisions, and tell you how nock is doing.

Getting started

One command, then commit.

$ cd your-repository
$ uvx --from git+https://github.com/logika-labs/nock nock init
$ git add -A && git commit -m "Add nock"

nock vendors itself into .nock/ — standard-library Python 3.12, no dependencies, your code from then on — imports a short primer into CLAUDE.md, and wires Claude Code's hooks. Every session after that starts with the toolbox listed.
