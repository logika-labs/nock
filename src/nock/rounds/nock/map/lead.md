# The map round

1. Dispatch the `nock-map` subagent with its material (below) and the
   round's window. It keeps `.nock/shared/map.md`, reading its own brief; it
   commits nothing. If it fails, say so in the report; don't do its part
   yourself.
2. Write `report.md` for the owner: what changed in the map and why.
3. Submit with the part's changes (kinds change, other). It runs the
   `nock-map` check, refusing while a citation names no decision, and
   commits the map and the record.
