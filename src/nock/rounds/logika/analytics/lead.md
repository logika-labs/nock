# The logika analytics round

Run `.nock/nock docs reflection.logika.lead` and do what it says for the
analytics: dispatch the `logika-analytics` subagent with its material
(below); you alone write `logika.json` and the code. Write `report.md`, then
submit with `"protocol": "logika.analytics"` and its changes (identity,
dimension, funnel, milestone, view, instrumentation, other). It requires the
ledger to parse and commits `logika.json` and the record.
