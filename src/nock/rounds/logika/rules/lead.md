# The logika rules round

Run `.nock/nock docs reflection.logika.lead` and do what it says for the
rules: dispatch one `logika-rules` subagent per directory `logika map`
shows gaps in, with its material (below) and its directory; you alone write
`logika.json` and the code. Write `report.md`, then submit with
`"protocol": "logika.rules"` and its changes (validate, path, timeout, rule,
invariant, error, risk, instrumentation, other). It requires the ledger to
parse and commits `logika.json` and the record.
