The guides are nock's documentation for people, nock.dev's docs: a few long essays, read in order, and the reference (`guide.commands`). Each is printed whole, since it runs long. Read one when a short term doesn't say enough: `.nock/nock docs guide.review`; an earlier guide's name (`guide.topics`) finds the essay that holds it now. Their links between pages (`#reviewing-in-work`) name another guide's heading.
