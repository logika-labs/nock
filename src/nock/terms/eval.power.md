---
term: eval.power
aliases: [power, reps, sample-size]
description: Run enough repetitions before a difference means something
---

Agents vary a lot from run to run. A difference whose interval spans zero is no difference yet: add repetitions (`rep` values) or units (bugs, tasks) before reading into it. `eval compare` pairs units when it can, which needs fewer. Spend a small budget first to see the spread, then size the run.
