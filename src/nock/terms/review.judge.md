---
term: review.judge
aliases: [judge, verdict, approve, approved, make-again]
description: The owner's word on an item: approved, rejected, a note
---

The owner judges an item's latest version: approved, rejected, or a note (`feedback`), in the studio or `review judge KEY '{"verdict": …, "feedback": …}'`; set them only when told to. Rejected, or noted and not approved, it waits for a new version, and a session the human starts lists it with the note: make it again (`review show KEY` has the recipe), answering the note in the new version's own.
