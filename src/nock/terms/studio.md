---
term: studio
aliases: [page, web, owner-page, chat, tidy]
description: nock studio: the owner's local page
---

`.nock/nock studio` (`--open`, `--port N`) serves the owner's page locally until stopped. Topics: each decision with its assets in a grid or a list, each in a viewer. Timeline: what happened, as notifications. The owner's message waits for your one answer (a message event); Address now sends an agent to answer it. A bar searches or asks (`nock consult`); Tidy up reorganizes the topics in one commit. A chat talks with a read-only agent. It is the owner's: an agent starts it only when asked.
