---
term: studio
aliases: [page, web, owner-page]
description: nock studio: the owner's local page
---

`.nock/nock studio` (`--open`, `--port N`) serves the owner's page until stopped: each task with what waits on them, its review told as a story or listed, Accept and Reject on proposals, notes on anything, one chat per task, Done, notifications, and the rounds that are due (Run starts one in the background). Send asks for an answer now: an agent waiting on `nock inbox --wait` gets it, else nock dispatches one. It is the owner's: an agent starts it only when asked.
