---
term: studio
aliases: [page, web, owner-page]
description: nock studio: the owner's local page
---

`.nock/nock studio` (`--open`, `--port N`) serves the owner's page until stopped: each task a row opening in place on its review, then its items and assets; Accept and Reject on proposals, notes, one chat per task, Done, plan progress, the round due (Run starts it in the background); the Timeline; notifications. Send asks for an answer now: an agent waiting on `nock inbox --wait` gets it, else nock dispatches one. It is the owner's: an agent starts it only when asked.
