---
term: assets.review
aliases: [approve, approved, make-again]
description: The owner's word on an asset: approved, rejected, a note
---

The owner reviews an asset's latest version: approved, rejected, or a note (`feedback`), in the studio or `assets review KEY JSON`; set them only when told to. Rejected, or noted and not approved, it waits for a new version, and a session the human starts lists it with the note: make it again (`assets show KEY` has the recipe), answering the note in the new version's own.
