term: reflection.logika.instrument
aliases: [logika-instrument]
description: "logika.instrument: one area instrumented and its rules written, by name, never due"
---

`reflect logika.instrument`, never adopted or due: an agent runs it for one area, does `logika docs instrument` and `logika docs rules` over it, then closes each item `logika map <area>` lists or gives it a reason. Its material is the repository's map at the start, with earlier rounds' reasons (`left:`). A reason is a change of kind `reason`, its target the item: `silent <file> <function>`, `verdicts <event>`, `unread <event>`.
