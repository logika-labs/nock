description: nock docs, and the project's own terms in .nock/docs/, read on top of nock's
---

`.nock/nock docs` lists the terms, `.nock/nock docs TERM…` prints them. A project adds its own in `.nock/docs/`: a file per term named by it (`billing.md`), front matter `term`, `aliases`, `description` between `---` lines, an article of at most 500 characters (`briefs/` and `guides/` beside it may run to 16,000). A project term of the same name replaces nock's. Write there what each area is for and why.
